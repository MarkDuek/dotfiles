# macOS Ghostty config

Catppuccin Mocha theme. Left Option acts as Alt; right Option keeps macOS special
characters.

Background opacity is `0.9` (90% opaque). Changing opacity requires a full
Ghostty restart; macOS native fullscreen disables transparency.

Link from the repository root:

```sh
stow --dir=macos --target="$HOME" ghostty
```

Reload Ghostty with `Cmd-Shift-,`.
